# Gita & Advaita AI – Domain-Specific LLM Chatbot

A domain-specific Large Language Model fine-tuned on **Bhagavad Gita and Advaita Vedanta philosophy** to provide spiritually grounded conversational responses.

This project was developed as part of a **Natural Language Processing coursework group project**.

---
## Project Overview

- **Model:** Llama 3.2 3B (Fine-tuned)
- **Fine-tuning Method:** QLoRA (Quantized Low-Rank Adaptation)
- **Framework:** Apple MLX
- **Hardware:** MacBook Pro (M3 Pro)
- **Dataset:** 18,000+ Vedic philosophy Q&A pairs
- **Deployment:** Streamlit + Hugging Face Spaces

The goal of the project was to build a **domain-specific conversational AI** capable of responding with philosophical insight grounded in Vedic texts while remaining lightweight enough to run on **consumer hardware**.
